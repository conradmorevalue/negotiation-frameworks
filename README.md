# Negotiation Frameworks — Grok Skill

A reusable Grok skill that teaches five proven negotiation frameworks for stronger deals:

1. **4 Phases** (Lewicki) — Preparation → Information Exchange → Bargaining → Commitment
2. **BATNA** (Fisher & Ury) — Best Alternative to a Negotiated Agreement
3. **Negotiation Matrix** (Lewicki & Hiam) — Choose strategy by outcome vs relationship
4. **Harvard Principled Negotiation** (Fisher, Ury & Patton) — Interests over positions
5. **ZOPA** (Fisher & Ury) — Zone of Possible Agreement

## What’s inside

| Path | Description |
|------|-------------|
| `SKILL.md` | Core skill instructions and how the frameworks work together |
| `references/diagnostics.md` | Diagnostic questions, failure modes, red flags |
| `references/examples-and-plays.md` | Situation-specific plays (salary, vendor, partnership, etc.) |
| `assets/negotiation-prep-template.md` | One-page prep checklist |

## How to use with Grok

Place the skill folder in your Grok skills directory. It will load automatically on questions about negotiations, BATNA, ZOPA, deal preparation, salary talks, etc.

Ask things like:
- “Help me prepare for a salary negotiation”
- “What’s my BATNA here and how do I improve it?”
- “Walk me through the 4 phases for this vendor deal”
- “Give me the one-page negotiation prep template”

**Core idea**: Great negotiators are the most prepared, not the most aggressive. Best deals happen when both sides feel heard.
